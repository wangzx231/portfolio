# 王姿骁 · 角色与造物

个人设计作品集网站，包含校园猫、Elio、校园纪念品、动画与视觉创作等六组项目。

## 网站内容

- 低饱和绿色主题与几何平面装饰
- 标题入场、滚动显现、图片视差、悬停交互
- 适配手机与系统「减少动态效果」设置
- 项目详情、个人经历、联系方式与原版 PDF 下载

## 文件结构

网站文件位于 `dist/`，可直接部署到静态网站托管服务，无需安装依赖或构建。

| 文件 | 用途 |
| --- | --- |
| `dist/index.html` | 页面内容 |
| `dist/style.css` | 配色与布局 |
| `dist/app.js` | 项目详情与浏览交互 |
| `dist/motion.css`、`dist/motion.js` | 动效 |
| `dist/assets/` | 作品图片与 PDF |

## 本地预览

直接打开 `dist/index.html`，或使用任意静态文件服务器，以 `dist/` 为网站根目录。
